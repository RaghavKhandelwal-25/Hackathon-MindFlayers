# "Scam or Legit?" game

A daily 7-card game that trains users to spot money scams.

- Backend: `backend/game_cards.py` (cards), `backend/game_service.py` (daily round, scoring), endpoint `GET /api/game/round`
- Frontend: `frontend/src/pages/Play.jsx`, `frontend/src/pages/play.css`, `frontend/src/services/gameService.js`
- Tests: `backend/test_game.py`
